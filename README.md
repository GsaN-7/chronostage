> **Кроссплатформенный таймер для проведения программ, совещаний, докладов, воркаутов и презентаций с календарем расписания и режимом ведущего.**

## 🌟 Возможности приложения

### 1. 🔄 Последовательные этапы с авторасчетом
* Создание регламентов и сценариев с неограниченным количеством этапов.
* Автоматический расчет времени начала и окончания каждого пункта от момента старта.
* Мгновенный пересчет последующих пунктов при корректировке текущего времени (+1 мин, +5 мин, -1 мин, -5 мин).
* Сравнение фактической суммы этапов с целевым планом встречи (*«Не распределено: 8 минут»*).

### 2. ⚡ Надежный таймер без рассинхронизации (Drift-Free)
* Таймер рассчитывает время строго по **абсолютным временным меткам** (`Date.now()`), а не по счетчику тиков.
* Не сбивается при блокировке экрана смартфона, сворачивании приложения или засыпании операционной системы.
* Автоматическое сохранение активной сессии — при перезагрузке страницы или смене устройства таймер продолжает идти.

### 3. 🖥️ Режим ведущего (Presenter Mode)
* Специальный высококонтрастный полноэкранный HUD для проекторов, ТВ и сценических суфлеров.
* Огромные моноширинные цифры (`tabular-nums`), читаемые с расстояния более 10 метров.
* Горячие клавиши: `Space` (старт/пауза), `Стрелки` (переход между этапами), `F` (полный экран), `Esc` (выход).
* **Screen Wake Lock API** — экран не гаснет во время выступления.

### 4. 📅 Расписание и календарь (Разделение Шаблонов и Событий)
* Независимость сущностей: программа — это шаблон, а событие — запланированный запуск со снимком (*snapshot*) пунктов.
* Режимы отображения: **День**, **Неделя**, **Месяц** и **Список**.
* Система периодических повторений: ежедневно, по рабочим дням, еженедельно по дням, ежемесячно.
* Экран **«Сегодня»** с живым обратным отсчетом до ближайшего события (*«До начала: 00:15:32»*) и кнопкой ручного досрочного старта.

### 5. 🔊 Звуковые и голосовые оповещения
* 4 типа синтезированных звуков (**Chime**, **Bell**, **Beep**, **Gong**) через Web Audio API (работает 100% офлайн без внешних mp3).
* Голосовой синтез на русском языке через Web Speech API: *«Заканчивается Первый доклад. Следующий пункт — Обсуждение»*.
* Тактильная вибрация на мобильных устройствах при завершении этапа.

### 6. 📱 Кроссплатформенность (PWA)
* Устанавливается как нативное приложение на **Windows**, **macOS**, **Linux**, **Android** и **iOS**.
* Адаптивный интерфейс: эргономичный мобильный таббар под палец одной руки на смартфонах и расширенная рабочая среда на ПК.
* Полный экспорт и импорт базы данных в формате JSON для резервного копирования и переноса между устройствами.

## 🚀 Быстрый старт

### Требования
* [Node.js](https://nodejs.org/) версии 18 или выше
* `npm` или `yarn` / `bun`

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/chronostage.git
   cd chronostage
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```
   Откройте в браузере: `http://localhost:3000` (или порт, указанный в терминале).

4. **Сборка для продакшна:**
   ```bash
   npm run build
   ```
   Собранные статические файлы будут находиться в папке `dist/`.

## 📂 Структура проекта

```
src/
├── types/                # TypeScript интерфейсы (Program, Event, Session, Recurrence)
├── utils/
│   ├── time.ts           # Расчет таймлайнов, форматирование времени и дат
│   ├── audio.ts          # Синтезатор Web Audio API и голосовой движок Web Speech
│   ├── notifications.ts  # Push-уведомления и Vibration API
│   ├── wakelock.ts       # Удержание экрана активным (Screen Wake Lock)
│   └── recurrence.ts     # Расчет повторений событий в календаре
├── services/
│   └── storage.ts        # LocalStorage, демо-данные, экспорт/импорт JSON
├── context/
│   ├── AppContext.tsx    # Управление программами, событиями и настройками
│   └── TimerContext.tsx  # Ядро таймера с абсолютными временными метками
├── components/
│   ├── common/           # Навигация, PWA кнопки, заголовки
│   ├── today/            # Главный экран "Сегодня" и обратный отсчет
│   ├── schedule/         # Календарь (День/Неделя/Месяц) и модальное окно
│   ├── programs/         # Библиотека шаблонов и редактор пунктов
│   ├── timer/            # Рабочий экран таймера и Режим ведущего (Presenter)
│   ├── history/          # Журнал завершенных сессий и фактический тайминг
│   └── settings/         # Настройки аудио, голоса и резервные копии
├── App.tsx               # Главный компонент и роутинг экранов
└── index.css             # Стили Tailwind CSS v4
```

## 🌐 Развертывание (Деплой)

Приложение полностью статическое (SPA + PWA) и может быть развернуто бесплатно на любом хостинге:

* **Vercel**: `vercel deploy`
* **Netlify**: перетащите папку `dist` или подключите репозиторий
* **GitHub Pages**: настройте GitHub Actions на ветку `main`
* **Cloudflare Pages**: выберите фреймворк Vite и команду `npm run build`
